# Lightweight Code Review

A useful review should make a contribution easier to trust and maintain.

## Review Steps

1. Read the linked issue and confirm the pull request addresses its goal.
2. Check that the change is focused and does not include unrelated files.
3. Verify technical correctness and reproduce the contributor's checks.
4. Review names, explanations, and documentation for clarity.
5. Leave specific, respectful feedback and distinguish required fixes from
   optional suggestions.

Approve only when required concerns are resolved. Summarize why the change is
ready so the final decision is easy to understand later.
