# Collaboration Exercise

Use this exercise to practice sharing responsibility for one small change.

## Exercise

1. Agree on a documentation problem and define a narrow outcome.
2. Let one collaborator draft the change on a short-lived branch.
3. Credit both contributors with Git's co-author metadata.
4. Open a pull request from the contributor's fork.
5. Discuss the result, merge it, and confirm both contributors are linked.

Co-author metadata should represent real joint work. It must not be added merely
to inflate contribution counts or attribute work to someone who did not
participate.
