# GitHub Collaboration Practice

This repository is a small, practical guide for learning a clean GitHub
collaboration workflow: issues, focused branches, pull requests, and merges.

## Workflow

1. Describe one focused improvement in an issue.
2. Create a short-lived branch for that improvement.
3. Make a small commit with a clear message.
4. Open a pull request that explains the change.
5. Review and merge the pull request, then remove the branch.

## Purpose

The examples here are intentionally documentation-only, making the repository
safe for practicing collaboration without affecting a production project.
